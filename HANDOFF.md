## What worked

- Reviewing small diffs in the main loop instead of fanning reviewer agents:
  four ~150-line PRs cost a fraction of a two-axis review each and still caught
  the inline-script bug that CI missed.
- Serial rebase + merge when every branch touches `global.css`; conflicts were
  all "each branch deleted its own legacy selector" and resolved mechanically.
- Designing on the canvas with a generator + Playwright pixel checks (see the
  epic); re-measure after each change rather than trusting CSS math.

## What didn't work / gotchas

- `is:inline` scripts are shipped verbatim: no TypeScript syntax in them.
- `gh pr checks --watch` binds only the rows present at start; poll
  `--json bucket` until at least three rows are non-pending.
- `jq` is not installed on this machine; use `gh --jq`.
- Google Fonts CSS returns `woff2` URLs only with a modern browser user agent.
- The resume sheet must NOT follow the site theme (it is a paper artefact).
- Auto-mode classifier blocks `rm`/`git rm` of tracked files in some modes;
  leave deletions to Avi in the run-list when that happens.

rescue); aggregator "rolling pages" overwrite yearly, only Wayback keeps old
states; `find-sets.mjs` has transient fetch failures by design — it's resumable,
